# Clash Royale card portraits

These 50 PNGs are the actual standard Clash Royale card images, downloaded unchanged from [RoyaleAPI's public asset collection](https://github.com/RoyaleAPI/cr-api-assets/tree/master/cards) on 2026-11-16. They replace generated portraits everywhere: deck slots, collection, card details, battle hand, next card, and drag previews.

`manifest.json` records the source URL, upstream Git blob SHA, local SHA-256, dimensions, and byte count for each file. Refresh with `node tools/fetch-card-art.mjs` from the project root (requires the matching GitHub directory index in `tools/card-assets-index.json`).
